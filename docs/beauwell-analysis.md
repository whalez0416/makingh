브리프 §4 의 순서(숫자 스트립·후기·의료진이 들어가고 클리닉 그리드가 6번으로 밀림)는
발주자가 디토셀에 맞게 재구성한 것이다. **순서는 브리프를 따르고, 각 섹션의 내부 구성만 여기서 가져온다.**

숫자 스트립(§4-2)·고객 후기(§4-7)·의료진(§4-8)은 뷰웰에 대응 섹션이 없다 — 디토셀 고유 추가다.

## 1. 히어로 (§4-1)

- 좌상단 **대형 철학 문장 2줄** + 그 오른쪽에 슬라이드 카운터 `02 / 04` + 긴 밑줄 + 화살표
  → 헤드라인 자체가 4장으로 교체된다
- 아래 **비대칭 3카드 bento**
  - 왼쪽 큰 카드(≈890×545): 사진 + [클리닉명(액센트, 작게)] + [설명 2줄(흰색 볼드)]
  - 오른쪽 위(≈450×300): 사진 + 상단 설명 + 하단 [클리닉명] + [헤드라인 2줄]
  - 오른쪽 아래(≈450×230): 그라데이션 + 제품명 + 설명 2줄

브리프 §4-1 은 히어로를 "풀스크린, 테마별 문법"으로 따로 지정했으므로 이 bento 는 히어로가 아니라
**§4-3 철학 헤드라인 교차 섹션**의 원본이다. "처방전과 숫자 너머" 문장이 여기 있다.

## 2. 전문 클리닉 (§4-6)

- 헤더 중앙정렬: eyebrow(액센트) + h2
- **탭 7개** 중앙정렬, 활성=진하게 / 비활성=회색
- **코버플로우 슬라이더**: 카드가 원근으로 기울고 중앙 카드만 확대·활성
  - 활성 카드 = 사진 + [분류(액센트)] + [제목] + [장비·시술 목록]
  - 비활성 카드 = 사진 + 아래에 [분류] + [제목]만
- 좌우 화살표

디토셀은 메뉴가 5개뿐이라 축소판(탭 4개)으로 간다. 코버플로우까지 갈 필요는 없다.

## 3. 자가진단 ★ (§4-4)

가장 많이 차용할 섹션. 균등 카드 그리드가 아니다.

- 헤더: eyebrow + h2 + **우측에 "상담 예약하기"**(긴 밑줄 + 화살표)
- **말풍선 9개를 5열(`q-col`)에 지그재그로 흩뿌린다**
  - 폭은 253px 균일, **높이는 3단(200 / 268 / 410)**
  - 컬럼마다 세로 시작점이 달라 어긋난다
  - 말풍선 **꼬리가 좌/우 교차** (`left` / `right`, 일부 `notail`)
  - 배경 4종 변주: 액센트 솔리드 2장 / 화이트 / 어두운 틴트 / **사진** 2장
  - 우측 상단에 큰 **따옴표 워터마크**
- 말풍선 내부는 `<dl>`: [분류 라벨(작게, 액센트)] + [환자 고민 문장(크게, 2~3줄)]
- 모바일(375): **2열**로 접히고 높이가 120~126px 로 균일해진다. 꼬리 좌/우는 유지.
  CTA 는 헤더 우측 → **하단 중앙**으로 내려간다

디토셀에 옮길 때: 따옴표 자리에 〃(ditto mark)를 쓴다 — 브랜드 모티프가 곧 따옴표라 그대로 맞는다.

## 4. 패키지 프리뷰 (§4-5)

- 헤더 중앙: eyebrow + h2, 우측에 "더보기" 화살표
- **카드 슬라이더**(≈320×460). 브리프의 "번호 인덱스 리스트"와 다르다 — 메인은 카드, 리스트는 서브페이지
  - 카드 상단: `01` ↔ `Cellulite` 양끝 정렬 (번호 / 영문 카테고리)
  - 중앙: 유기적 마스크를 씌운 이미지
  - 하단: [패키지명 볼드] + [설명 2줄]
- 하단 좌우 화살표

## 5. News (§4-9)

"Beauwell News" + 더보기 + **Blog / Instagram / Youtube 탭** + 글 목록.
디토셀 후기(§4-7)를 인스타 릴스로 가는 것과 맞물린다.

## 6. 클로징 (§4-11)

`display:flex`, 900px 풀. 대형 선언문 한 문장 + "상담 예약하기". 그 아래 바로 푸터.

## 서브·상세 페이지 (2026-08-21 추가 실측, 1440px)

메인과 서브는 문법이 다르다. 서브 3종을 렌더해 확인한 구조:

### 시술 상세 (/face/onda/, 전체 10125px)
1. **컬러 히어로 밴드** — 브랜드 컬러 솔리드 풀폭. 영문 시술명 eyebrow + 대형 국문 시술명(좌) + 설명 문단(우) + 아래 풀폭 비주얼
2. 고민 말풍선 4개 — 메인 자가진단 패턴을 상세에서 재사용 (따옴표 워터마크 포함)
3. "SPECIAL" 특장점 카드 4개 (그라데이션 카드, 중앙 헤드라인)
4. 풀폭 원리 배너 — 사진+오버레이+한 문장
5. 2열 스펙 블록 — 영문 모노 레이블 + 제목 + 설명
6. 부위/적응증 — 헤드라인 + 아이콘 아이템, 핸드피스별 번호 리스트
7. **시술 안내 표** — 시술 시간 / 권장 주기 / 효과 시기 3열 + 사후 관리 불릿
8. **클로징 배너** — 사진 + 선언문 + 상담 CTA
9. 연관 시술 카드 3개 ("같이 받으면 좋아요")

### 패키지 목록 (/package/)
중앙 대형 타이틀 + 한 줄 소개 → **2열 대형 카드** (유기적 마스크 사진 + 영문 카테고리(액센트) + 국문 패키지명 + 설명 2줄 + more 버튼), 행 사이 헤어라인

### 소개 (/about/)
다크 선언문 히어로 → INTRODUCE 철학 블록(좌 텍스트+우 오브제) → 풀폭 추상 그래픽 밴드 → 다크 비전 섹션(원형 카드 3개)

### 디토셀 적용 방침
- 서브 최상단은 **다크 그라데이션 히어로 밴드**(rounded 카드형 — 투명 헤더의 가독성 때문에 풀블리드 대신 메인 히어로 카드와 같은 라운딩 카드로, 헤더 아래에서 시작)
- 서브 하단 공통 **클로징 CTA 배너** (상세 8번 패턴)
- 시술 안내 표(시간·주기·효과)는 원고 수급 후 추가 — 데이터 없이 만들지 않는다
- /signature 는 브리프 명시대로 번호 인덱스 리스트 유지 (뷰웰의 2열 카드는 사진 수급 후 검토)

## 차용하지 않는 것 (브리프 §4)

메가메뉴, 동시 다중 팝업, 과다 플로팅 버튼.
실제로 뷰웰은 진입 시 5장짜리 프로모션 팝업 캐러셀이 화면을 덮고, 플로팅이 3개 떠 있다.
